# Website Environment

Die Webseite des KKHT SWK basiert auf dem CMS Wordpress, inder jeweils aktuellsten Version (aktuell 6.7.1). Dazu sind zahlreiche Plugins installiert, die verschiedene Funktionen bereit stellen. Aktuell sind dies im Einzelnen:

- AcyMailing - _Versand des SWK Newsletters_
- Advanced Custom Fields PRO - _Implementierung zahlreicher Customer Fields, die bei der Seitenerstellung verwendet werden_
- All In One Security (AIOS) - _Allgemeine Sicherheit, insbeosndere auch Firewall_
- Better Search Replace - _Suchen und Ersetzen in WordPress Inhalten_
- Classic Editor - _Der klassische Editor_
- Koko Analytics - _Einfaches Nutzeranalyse-Tool_
- Phoenix Media Rename - _Erlaubt Umbennenung von Bildern etc._
- PublishPress Capabilities - _Erweitertes Rechtekonzept_
- Real Media Library (Free) - _Virtuelle Ordnder in der Medienbibliothek_
- Redirection - _Erstelle beliebige redirects_
- Simple History - _Sehr einfaches Tracking von Aktivitäten_
- UpdraftPlus - Backup/Restore - _Lokale Backups_
- WP Mail SMTP - _Mail-Versand per SMTP_
- XML Sitemap Generator for Google - _Sitemap_


Einige der genannten Plugins sind für die Entwicklungsumgebung nicht notwendig, sondern sogar störend. Man sollte sie daher dort **nicht** verwenden:

- All in One Security
- Koko Analytics
- Updraft Plus
- XML Sitemap Generator for Google

Statt dessen empfiehlt sich z.B der Einsatz des Debug Bar Plugins, oder des acf-php-to-json plugins
